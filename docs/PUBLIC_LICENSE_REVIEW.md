**Technical review status: PASS**

This document records a technical license and redistribution review prepared
on 2026-07-14. It is not legal advice and does not guarantee compliance in
every jurisdiction or distribution scenario.

CaribeOS is an independent experimental project. It is not affiliated with,

## Owner Decision And Scope

On 2026-07-15, the owner explicitly approved BSD-2-Clause for original
CaribeOS runtime code, with:

- `Copyright (c) 2026 h0nda1337`;
- `SPDX-License-Identifier: BSD-2-Clause`;
- no relicensing of third-party, derived, generated, binary, data, or
  mixed/uncertain-provenance material.

The canonical license text is in `LICENSE`. The exact original-code allowlist,
generated exclusion, reviewed non-code boundaries, and future fail-closed
policy are in `docs/RUNTIME_LICENSE_SCOPE.json`.

The scoped transformation applied headers to 138 tracked original-code files.
Every resulting file was reconstructed as its exact pre-license Git body plus
the approved comment header. `mfw/virt_dtb.c` remains explicitly excluded as a
generated byte array. No tracked file under `third_party/` entered the scope.

## Developer Preview

The preserved preview SHA-256 is
`30cfc3089bee97053c262c9278325b16274efdf21c1aa372ebaec2b45f33650d`.
A structured audit found 40 ZIP entries and a valid `cpio-newc` initrd with 50
entries, including one GNU Bash ELF. The package includes APSL, Bash GPL v3,
and musl license texts. It does not bundle QEMU or OpenSBI.

The immutable preview archive does not contain corresponding Bash/musl source.
The separately verified same-place asset
`caribeos-tranche-201-corresponding-source.zip` supplies the exact Bash and
musl archives, all five Bash patches, required build/control scripts, licenses,
runtime source snapshots, and a hash manifest. The preserved preview ZIP is
not overwritten. This separation is a binary-distribution boundary, not a
change to the approved CaribeOS source license.
